# App_Bank

Курсовой проект для анализа банковских транзакций на Python.

## Описание

Приложение обрабатывает банковские операции из Excel-файла `operations.xlsx`.

Реализованы следующие направления:

- Анализ банковских операций по выбранному периоду.
- Поиск транзакций по описанию и категории.
- Формирование отчёта о средних тратах по дням недели.

## Используемые технологии

- Python 3.12
- Pandas
- Requests
- OpenPyXL
- Pytest
- Poetry

## Установка зависимостей

```bash
poetry install --no-root
```

## Тестирование

```bash
poetry run python -m pytest -v
```

## Структура проекта

- `src/` — основной код приложения.
- `data/` — исходные данные и результаты работы.
- `tests/` — модульные тесты.
- `logs/` — файлы журналирования.
